# Translator and Vocabulary Book

A Chrome/Edge browser extension that helps you learn new languages by translating selected text and building your personal vocabulary collection. Perfect for students, language learners, and anyone looking to expand their vocabulary while browsing the web.

## Features

- 🌐 **Instant Translation**: Select any text on a webpage to get instant translations
- 📚 **Vocabulary Collection**: Save words and phrases to your personal vocabulary book
- 🔄 **Review System**: Review your saved words with flashcard-style learning
- 💾 **Local Storage**: All your vocabulary is stored locally in your browser
- 🎯 **Customizable**: Configure translation settings and preferences
- 📊 **Track Progress**: Keep track of the words you've learned

## Installation

### Step 1: Download the Extension

1. Download this repository as a ZIP file:
2. Extract the ZIP file to a location on your computer

### Step 2: Install in browser

1. Open your Chromium-based browser (Chrome/Edge)
2. Navigate to `chrome://extensions/` or `edge://extensions/`  in your address bar
3. Enable **Developer mode** by toggling the switch in the top-right corner
4. Click the **Load unpacked** button that appears
5. Navigate to the extracted folder and select it
6. The extension should now appear in your extensions list and be ready to use!

### Step 4: Pin the Extension (Optional but Recommended)

1. Click the **Extensions** icon (puzzle piece) in your browser toolbar
2. Find "Translator and Vocabulary Book" in the list
3. Click the **pin** icon next to it
4. The extension icon will now appear in your toolbar for easy access

## Usage

### Translating Text

1. Select any text on a webpage
2. The translation popup will appear automatically
3. View the translation and save words you want to remember

### Managing Your Vocabulary

1. Click the extension icon in your toolbar to view recent words
2. Click **Open Main Page** to see your complete vocabulary collection
3. Use the review feature to practice your saved words

### Configuring Settings

1. Click the extension icon in your toolbar
2. Click the **Settings** button ⚙️
3. Configure your translation preferences and API settings

## Configuration

Before using the extension, you may need to configure:
- Google Gemini API settings

Access these settings by clicking the settings icon in the extension popup.
